# BibliotecaMVC

Web application for library management developed with ASP.NET Core MVC and Razor Views.

## Overview

BibliotecaMVC is an academic project focused on building a web-based library management system. The application allows users to manage books, authors, and categories through a structured MVC architecture.

## Features

- Book management
- Author management
- Category management
- CRUD operations
- Data validation
- Responsive user interface
- SQL Server database integration
- Entity Framework Core
- Bootstrap styling

## Technologies

- C#
- ASP.NET Core MVC
- Razor Views
- Entity Framework Core
- SQL Server
- Bootstrap

## Architecture

The project follows the Model-View-Controller (MVC) pattern:

- **Models** — Application entities and data structure.
- **Views** — User interface implemented with Razor.
- **Controllers** — Application logic and request handling.
